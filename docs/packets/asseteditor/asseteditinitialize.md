# AssetEditInitialize

Initializes the asset editor session.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 302 |
| **Direction** | Client ↔ Server |
| **Compressed** | No |
| **Max Size** | 0 bytes |

## Fields

This packet has no fields.

## Usage

This packet is sent to initialize the asset editor. It signals that the client is ready to begin an asset editing session and triggers the server to prepare the necessary editor state.
