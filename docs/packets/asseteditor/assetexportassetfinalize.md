# AssetExportAssetFinalize

Finalizes the export of an asset.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 345 |
| **Direction** | Client ↔ Server |
| **Compressed** | No |
| **Max Size** | 0 bytes |

## Fields

This packet has no fields.

## Usage

This packet signals that all parts of an asset export have been sent. The receiving end can now process and assemble the complete export data.
