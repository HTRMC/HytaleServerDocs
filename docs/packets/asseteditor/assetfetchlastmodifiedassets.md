# AssetFetchLastModifiedAssets

Requests the list of recently modified assets.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 338 |
| **Direction** | Client ↔ Server |
| **Compressed** | No |
| **Max Size** | 0 bytes |

## Fields

This packet has no fields.

## Usage

This packet requests a list of the most recently modified assets. It is used to populate the recent files view and track changes made during the editing session.
