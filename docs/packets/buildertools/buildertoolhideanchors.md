# BuilderToolHideAnchors

Hides all visible anchor points.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 416 |
| **Direction** | Client -> Server |
| **Compressed** | No |
| **Max Size** | 0 bytes |

## Fields

This packet has no fields.

## Usage

Sent by the client to hide all currently visible anchor points in the editor. Used to clear anchor visualizations when they are no longer needed.
