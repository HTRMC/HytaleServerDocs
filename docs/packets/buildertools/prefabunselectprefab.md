# PrefabUnselectPrefab

Deselects the currently selected prefab.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 417 |
| **Direction** | Client -> Server |
| **Compressed** | No |
| **Max Size** | 0 bytes |

## Fields

This packet has no fields.

## Usage

Sent by the client to deselect the currently selected prefab in the editor. Clears the prefab selection state.
