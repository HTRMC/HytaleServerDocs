# ClearDebugShapes

Clears all debug shapes from the display.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 115 |
| **Direction** | Client → Server |
| **Compressed** | No |
| **Size** | 0 bytes (empty) |

## Fields

This packet has no fields.

## Usage

Sent by the client to request clearing all debug visualization shapes.
