# DisplayDebug

Sends debug display information.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 114 |
| **Direction** | Client → Server |
| **Compressed** | No |
| **Max Size** | 32,768,037 bytes |

## Fields

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| debugData | Variable | No | Debug display information |

## Usage

Sent by the client to transmit debug display data for development and troubleshooting purposes.
