# UpdateModelVFXs

Updates model visual effects definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 53 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update model VFX definitions. Model VFX are visual effects attached to 3D models, such as glowing effects, auras, or other visual enhancements.
