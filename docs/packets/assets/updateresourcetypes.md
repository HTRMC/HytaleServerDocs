# UpdateResourceTypes

Updates resource type definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 59 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update resource type definitions. Resource types define gatherable materials and their properties, such as ores, wood, or other raw materials used in crafting.
