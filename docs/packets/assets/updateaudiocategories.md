# UpdateAudioCategories

Updates audio category definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 80 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update audio category definitions. Audio categories group sounds for volume control, allowing players to adjust music, effects, and ambient sounds independently.
