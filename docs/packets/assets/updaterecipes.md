# UpdateRecipes

Updates crafting recipe definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 60 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update crafting recipe definitions. Recipes define the ingredients, quantities, and results for crafting items, as well as any required crafting stations or conditions.
