# UpdateHitboxCollisionConfig

Updates hitbox collision configuration on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 74 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 36,864,011 bytes |

## Usage

This packet is sent by the server to update hitbox collision configuration. This defines how different hitbox types interact with each other and what collision responses should occur.
