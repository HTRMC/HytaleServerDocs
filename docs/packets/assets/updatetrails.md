# UpdateTrails

Updates particle trail definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 48 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update trail definitions. Trails are particle effects that follow moving objects or entities, such as projectile trails or movement effects.
