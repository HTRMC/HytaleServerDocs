# UpdateSoundEvents

Updates sound event definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 65 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update sound event definitions. Sound events map game actions and triggers to specific audio files and playback parameters.
