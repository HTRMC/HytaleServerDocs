# UpdateEntityEffects

Updates entity visual effect definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 51 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update entity effect definitions. Entity effects are visual effects applied to entities such as status indicators, damage effects, or special abilities.
