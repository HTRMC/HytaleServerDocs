# UpdateFluidFX

Updates fluid effect definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 63 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update fluid effect definitions. Fluid effects include visual and audio properties for liquids such as water splashes, lava bubbles, or other fluid interactions.
