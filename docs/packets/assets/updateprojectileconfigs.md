# UpdateProjectileConfigs

Updates projectile configuration definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 85 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update projectile configuration definitions. Projectile configs define the behavior of thrown or shot objects including speed, trajectory, gravity, and impact effects.
