# UpdateReverbEffects

Updates reverb and echo effect definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 81 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update reverb effect definitions. Reverb effects add spatial audio properties like echo and room acoustics based on the environment.
