# UpdateInteractions

Updates NPC and entity interaction definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 66 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update interaction definitions. Interactions define how players can interact with NPCs and entities, including dialogue options, trade menus, and other interactive behaviors.
