# UpdateTagPatterns

Updates tag pattern definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 84 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update tag pattern definitions. Tag patterns define matching rules for categorizing and grouping game elements using a tagging system.
