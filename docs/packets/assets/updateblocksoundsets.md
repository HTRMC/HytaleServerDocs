# UpdateBlockSoundSets

Updates block audio definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 42 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update block sound set definitions. Sound sets define the audio played when interacting with blocks, including footstep sounds, breaking sounds, and placement sounds.
