# UpdateWeathers

Updates weather definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 47 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update weather type definitions. Weather definitions include parameters for rain, snow, storms, and other atmospheric conditions that affect the game world's visual and audio presentation.
