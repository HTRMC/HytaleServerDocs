# UpdateFieldcraftCategories

Updates fieldcraft category definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 58 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update fieldcraft category definitions. Fieldcraft categories organize crafting recipes available in the field, outside of dedicated crafting stations.
