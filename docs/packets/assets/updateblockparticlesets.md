# UpdateBlockParticleSets

Updates block particle effect definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 44 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update block particle set definitions. These define the particle effects displayed when blocks are broken, walked on, or otherwise interacted with.
