# UpdateItemReticles

Updates item reticle and crosshair data on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 57 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update reticle definitions for items. Reticles are crosshair visuals displayed when aiming or using items, which may vary based on item type or state.
