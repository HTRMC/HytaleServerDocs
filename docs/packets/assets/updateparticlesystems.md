# UpdateParticleSystems

Updates particle system definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 49 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update particle system definitions. Particle systems define complex particle effects including emission patterns, particle behaviors, colors, and lifetimes used throughout the game.
