# UpdateAmbienceFX

Updates ambient effect definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 62 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update ambient effect definitions. Ambient effects include background sounds, environmental particles, and other atmospheric elements that enhance immersion.
