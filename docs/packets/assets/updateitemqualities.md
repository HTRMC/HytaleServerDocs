# UpdateItemQualities

Updates item quality level definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 55 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update item quality definitions. Item qualities define rarity tiers and their associated properties such as color coding, stat modifiers, or visual indicators.
