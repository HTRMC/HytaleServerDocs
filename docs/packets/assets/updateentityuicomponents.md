# UpdateEntityUIComponents

Updates entity UI component definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 73 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update entity UI component definitions. UI components define visual elements displayed for entities, such as health bars, nameplates, or status indicators.
