# UpdateEnvironments

Updates environmental settings definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 61 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update environment definitions. Environments define biome-specific settings including lighting, fog, sky colors, and other atmospheric properties.
