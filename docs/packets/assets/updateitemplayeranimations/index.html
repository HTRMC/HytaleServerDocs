UpdateItemPlayerAnimations

Updates item-related player animation data on the client.

Packet Info​

PropertyValue
Packet ID52
DirectionServer to Client
CompressedYes
Max Size1,677,721,600 bytes

Usage​

This packet is sent by the server to update animation definitions for items. This includes animations played when wielding, using, or interacting with different item types.
