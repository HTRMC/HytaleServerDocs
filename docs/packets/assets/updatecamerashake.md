# UpdateCameraShake

Updates camera shake configuration on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 77 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update camera shake configuration. Camera shake effects are used for impacts, explosions, or other events that should create screen movement feedback.
