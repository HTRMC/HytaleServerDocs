# UpdateRootInteractions

Updates root interaction definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 67 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update root interaction definitions. Root interactions define the base-level interaction options that serve as entry points for interaction trees.
