# UpdateBlockHitboxes

Updates block collision data on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 41 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update block hitbox and collision data. Block hitboxes define the physical boundaries used for collision detection, raycasting, and player/entity interactions with blocks.
