# UpdateItemSoundSets

Updates item audio definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 43 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update item sound set definitions. These define the audio played when using, equipping, or interacting with items.
