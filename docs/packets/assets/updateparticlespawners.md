# UpdateParticleSpawners

Updates particle spawner definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 50 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update particle spawner definitions. Spawners define how and when particles are emitted, including spawn rates, positions, and initial particle properties.
