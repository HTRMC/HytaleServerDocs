# UpdateSoundSets

Updates sound set definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 79 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update sound set definitions. Sound sets group related audio files together for randomized playback and variation in game audio.
