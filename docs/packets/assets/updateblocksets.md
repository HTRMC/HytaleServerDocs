# UpdateBlockSets

Updates block grouping definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 46 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update block set definitions. Block sets group related blocks together for organizational purposes, such as categorizing blocks by material type or biome.
