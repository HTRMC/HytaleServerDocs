# UpdateItems

Updates item definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 54 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update item definitions. Items define all collectable and usable objects in the game, including their properties, behaviors, and visual representations.
