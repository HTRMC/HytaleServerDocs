# UpdateBlockGroups

Updates block grouping definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 78 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update block group definitions. Block groups organize blocks into logical collections for game mechanics, recipes, or tool interactions.
