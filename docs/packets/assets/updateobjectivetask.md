# UpdateObjectiveTask

Updates task progress within an objective.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 71 |
| **Direction** | Server to Client |
| **Compressed** | No |
| **Max Size** | 16,384,035 bytes |

## Usage

This packet is sent by the server to update individual task progress within an objective. Tasks are sub-goals within objectives that track specific completion criteria.
