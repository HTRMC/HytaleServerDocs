# UpdateEqualizerEffects

Updates audio equalizer settings on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 82 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update equalizer effect definitions. Equalizer effects modify audio frequency response for different environments or situations.
