# UpdateViewBobbing

Updates camera bobbing configuration on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 76 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update view bobbing configuration. View bobbing controls the camera movement when walking or running to simulate natural head motion.
