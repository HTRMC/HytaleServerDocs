# UpdateUnarmedInteractions

Updates unarmed combat interaction definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 68 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 20,480,007 bytes |

## Usage

This packet is sent by the server to update unarmed interaction definitions. Unarmed interactions define combat moves and actions available when the player has no weapon equipped, such as punches or kicks.
