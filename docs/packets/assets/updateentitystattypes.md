# UpdateEntityStatTypes

Updates entity stat type definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 72 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update entity stat type definitions. Stat types define attributes like health, stamina, mana, or custom stats that entities can possess.
