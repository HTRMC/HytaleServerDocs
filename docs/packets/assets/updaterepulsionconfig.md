# UpdateRepulsionConfig

Updates repulsion settings configuration on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 75 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 65,536,011 bytes |

## Usage

This packet is sent by the server to update repulsion configuration. Repulsion settings control how entities push away from each other to prevent overlap and maintain proper spacing.
