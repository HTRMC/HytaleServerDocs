# UpdateBlockBreakingDecals

Updates block breaking visual effect definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 45 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update block breaking decal definitions. Decals are visual overlays shown on blocks as they are being damaged, typically displaying cracks or fractures to indicate breaking progress.
