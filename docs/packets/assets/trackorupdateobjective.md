# TrackOrUpdateObjective

Tracks or updates objective data on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 69 |
| **Direction** | Server to Client |
| **Compressed** | No |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to track a new objective or update an existing one. Objectives represent quests, missions, or goals that players can pursue, with progress tracked by the client.
