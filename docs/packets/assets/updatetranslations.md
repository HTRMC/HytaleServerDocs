# UpdateTranslations

Updates language translation data on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 64 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update translation strings for localization. Translations allow the game to display text in different languages based on player preferences.
