# UpdateFluids

Updates fluid type definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 83 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update fluid type definitions. Fluids define liquid properties such as water and lava, including their flow behavior, visual appearance, and interaction effects.
