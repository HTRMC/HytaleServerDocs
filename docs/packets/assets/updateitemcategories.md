# UpdateItemCategories

Updates item category definitions on the client.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 56 |
| **Direction** | Server to Client |
| **Compressed** | Yes |
| **Max Size** | 1,677,721,600 bytes |

## Usage

This packet is sent by the server to update item category definitions. Categories organize items into groups such as weapons, tools, materials, or consumables for inventory management and UI display.
