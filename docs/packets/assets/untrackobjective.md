# UntrackObjective

Removes an objective from client tracking.

## Packet Info

| Property | Value |
|----------|-------|
| **Packet ID** | 70 |
| **Direction** | Server to Client |
| **Compressed** | No |
| **Max Size** | 16 bytes |

## Usage

This packet is sent by the server to remove an objective from the client's tracking list. This is used when a quest or mission is completed, abandoned, or no longer relevant.
