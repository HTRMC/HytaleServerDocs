SetCreativeItem

Sets an item in the player's inventory while in creative mode.

Packet Info​

PropertyValue
Packet ID171
DirectionClient → Server
CompressedNo
Max Size16384019 bytes

Fields​

FieldTypeNullableDescription
inventorySectionIdint (4 bytes)NoTarget inventory section identifier
slotIdint (4 bytes)NoTarget slot index within the section
itemItemQuantityNoThe item and quantity to place
overrideboolean (1 byte)NoWhether to override existing item in slot

Usage​

Sent by the client in creative mode to place an item directly into a specific inventory slot. The override flag determines whether an existing item in the slot should be replaced.
