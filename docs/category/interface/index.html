Interface

Chat, HUD, and notification packets (IDs 210-234)

📄️ ServerMessage

Displays a server message to the client.

📄️ ChatMessage

Sends a chat message to be displayed in the client's chat interface.

📄️ Notification

Displays a notification popup to the client.

📄️ KillFeedMessage

Displays a kill feed entry in the client's HUD.

📄️ ShowEventTitle

Displays an event title on the client's screen.

📄️ HideEventTitle

Immediately hides any currently displayed event title.

📄️ SetPage

Instructs the client to display a specific UI page.

📄️ CustomHUD

Sends custom HUD configuration data to the client.

📄️ CustomPage

Sends custom page configuration data to the client.

📄️ CustomPageEvent

Sends a custom page interaction event from the client to the server.

📄️ EditorBlocksChange

Sends editor block modification data to the client.

📄️ ServerInfo

Sends server information to the client.

📄️ AddToServerPlayerList

Notifies the client that a player has joined the server.

📄️ RemoveFromServerPlayerList

Notifies the client that a player has left the server.

📄️ UpdateServerPlayerList

Updates player information in the client's player list.

📄️ UpdateServerPlayerListPing

Updates ping values for players in the client's player list.

📄️ UpdateKnownRecipes

Updates the list of recipes known to the player.

📄️ UpdatePortal

Sends portal information to the client.

📄️ UpdateVisibleHudComponents

Controls the visibility of HUD components on the client.

📄️ ResetUserInterfaceState

Resets the client's user interface to its default state.

📄️ UpdateLanguage

Updates the language setting for the client's interface.

📄️ WorldSavingStatus

Indicates whether the world is currently being saved.

📄️ OpenChatWithCommand

Opens the chat interface with a pre-filled command.
