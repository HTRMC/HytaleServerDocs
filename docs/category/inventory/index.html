Inventory

Inventory management packets (IDs 170-179)

📄️ UpdatePlayerInventory

Sends the complete player inventory state to the client, including all inventory sections.

📄️ SetCreativeItem

Sets an item in the player's inventory while in creative mode.

📄️ DropCreativeItem

Drops an item from creative mode into the world.

📄️ SmartGiveCreativeItem

Intelligently gives an item to the player in creative mode using smart placement logic.

📄️ DropItemStack

Drops a specified quantity of items from an inventory slot into the world.

📄️ MoveItemStack

Moves a specified quantity of items from one inventory slot to another.

📄️ SmartMoveItemStack

Intelligently moves items from an inventory slot using smart placement logic.

📄️ SetActiveSlot

Sets the currently active (selected) slot in an inventory section.

📄️ SwitchHotbarBlockSet

Switches the hotbar to display a specific block set category.

📄️ InventoryAction

Performs a generic inventory action on a specific inventory section.
