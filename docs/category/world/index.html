World

Chunks, blocks, and world state packets (IDs 131-159)

📄️ SetChunk

Sends chunk block data to the client.

📄️ SetChunkHeightmap

Sends chunk heightmap data to the client.

📄️ SetChunkTintmap

Sends chunk tint/color data to the client.

📄️ SetChunkEnvironments

Sends chunk environment data to the client.

📄️ UnloadChunk

Instructs the client to unload a chunk from memory.

📄️ SetFluids

Sends fluid state data for a chunk to the client.

📄️ ServerSetBlock

Updates a single block in the world.

📄️ ServerSetBlocks

Updates multiple blocks in the world in bulk.

📄️ ServerSetFluid

Updates a single fluid block in the world.

📄️ ServerSetFluids

Updates multiple fluid blocks in the world in bulk.

📄️ UpdateBlockDamage

Updates the damage state of a block being broken.

📄️ UpdateTimeSettings

Updates the world time configuration settings.

📄️ UpdateTime

Updates the current world time.

📄️ UpdateEditorTimeOverride

Sets an editor time override for development/testing.

📄️ ClearEditorTimeOverride

Clears the editor time override.

📄️ UpdateWeather

Updates the current weather state.

📄️ UpdateEditorWeatherOverride

Sets an editor weather override for development/testing.

📄️ UpdateEnvironmentMusic

Updates the current environment music.

📄️ SpawnParticleSystem

Spawns a particle system in the world.

📄️ SpawnBlockParticleSystem

Spawns a block-related particle system.

📄️ PlaySoundEvent2D

Plays a 2D (non-positional) sound effect.

📄️ PlaySoundEvent3D

Plays a 3D (positional) sound effect at a world location.

📄️ PlaySoundEventEntity

Plays a sound effect attached to an entity.

📄️ UpdateSleepState

Updates the sleep state UI and mechanics.

📄️ SetPaused

Client request to pause or unpause the game.

📄️ ServerSetPaused

Server confirmation of game pause state.

📄️ UpdateSunSettings

Updates the sun's visual settings.

📄️ UpdatePostFxSettings

Updates post-processing visual effects settings.
