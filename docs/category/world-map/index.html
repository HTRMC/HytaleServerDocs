World Map

Map display and teleportation packets (IDs 240-245)

📄️ UpdateWorldMapSettings

Configures the world map settings including biome data, teleport permissions, and zoom scale parameters.

📄️ UpdateWorldMap

Sends world map data updates including chunk imagery and marker changes to the client.

📄️ ClearWorldMap

Clears all world map data on the client, removing all chunks and markers.

📄️ UpdateWorldMapVisible

Controls the visibility state of the world map interface on the client.

📄️ TeleportToWorldMapMarker

Requests teleportation to a specific map marker by its identifier.

📄️ TeleportToWorldMapPosition

Requests teleportation to a specific coordinate position on the world map.
