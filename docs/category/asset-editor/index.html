Asset Editor

Development tool packets (IDs 300-355)

📄️ FailureReply

Failure response sent when an asset editor operation fails.

📄️ SuccessReply

Success response sent when an asset editor operation completes successfully.

📄️ AssetEditInitialize

Initializes the asset editor session.

📄️ AssetEditorAuthorization

Checks authorization status for asset editor access.

📄️ AssetEdiaCapabilities

Reports the capabilities available in the asset editor.

📄️ AssetEditorSetupSchemas

Sets up the JSON schemas used by the asset editor.

📄️ AssetEditorSetupAssetTypes

Sets up the available asset types in the editor.

📄️ AssetEditorCreateDiretory

Creates a new directory in the asset structure.

📄️ AssetEdiorDeleteDirectory

Deletes a directory from the asset structure.

📄️ AssetEditorEnameDirectory

Renames a directory in the asset structure.

📄️ AssetEdtorFetchAsset

Requests to fetch an asset from the server.

📄️ AssetEdtorFetchJsonAssetWithParents

Requests a JSON asset along with its parent chain.

📄️ AssetEdtorFetchAssetReply

Response containing the requested asset data.

📄️ AssetEdtorFetchJsonAssetWithParentsReply

Response containing a JSON asset and its parent chain.

📄️ AssetEdAssetPackSetup

Sets up asset packs in the editor.

📄️ AssetEdUpdateAssetPack

Updates an existing asset pack.

📄️ AssetEdCreateAssetPack

Creates a new asset pack.

📄️ AssetEdDeleteAssetPack

Deletes an asset pack.

📄️ AssetEnableAssetPack

Enables or disables an asset pack.

📄️ AssetEAssetListSetup

Sets up the initial asset list in the editor.

📄️ AssetEAssetListUpdate

Updates the asset list with changes.

📄️ AssetRequestChildrenList

Requests the list of children for an asset or directory.

📄️ AssetRequestChildrenListReply

Response containing the list of children.

📄️ AssetUpdateJsonAsset

Updates a JSON asset with new content.

📄️ AssetUpdateAsset

Updates a binary asset with new content.

📄️ AssetJsonAssetUpdated

Notification that a JSON asset has been updated.

📄️ AssetAssetUpdated

Notification that a binary asset has been updated.

📄️ AssetCreateAsset

Creates a new asset.

📄️ AssetRenameAsset

Renames an existing asset.

📄️ AssetDeleteAsset

Deletes an asset.

📄️ AssetDiscardChanges

Discards pending changes to an asset.

📄️ AssetFetchAutocompleteData

Requests autocomplete suggestions for the editor.

📄️ AssetFetchAutocompleteDataReply

Response containing autocomplete suggestions.

📄️ AssetRequestDataset

Requests a dataset for the editor.

📄️ AssetRequestDatasetReply

Response containing the requested dataset.

📄️ AssetActivateButton

Activates a button action in the editor.

📄️ AssetSelectAsset

Selects an asset in the editor.

📄️ AssetPopupNotification

Displays a popup notification in the editor.

📄️ AssetFetchLastModifiedAssets

Requests the list of recently modified assets.

📄️ AssetLastModifiedAssets

Response containing recently modified assets.

📄️ AssetModifiedAssetsCount

Reports the count of modified assets.

📄️ AssetSubscribeModifiedAssetsChanges

Subscribes to notifications about modified asset changes.

📄️ AssetExportAssets

Initiates an asset export operation.

📄️ AssetExportAssetInitialize

Initializes the export of a single asset.

📄️ AssetExportAssetPart

Sends a part of an asset export.

📄️ AssetExportAssetFinalize

Finalizes the export of an asset.

📄️ AssetExportDeleteAssets

Deletes assets during an export operation.

📄️ AssetExportComplete

Signals that an export operation is complete.

📄️ AssetRebuildCaches

Triggers a rebuild of asset caches.

📄️ AssetUndoChanges

Undoes the last change to an asset.

📄️ AssetRedoChanges

Redoes a previously undone change to an asset.

📄️ AssetUndoRedoReply

Response to an undo or redo operation.

📄️ AssetSetGameTime

Sets the game time for preview purposes.

📄️ AssetUpdateSecondsPerGameDay

Updates the seconds per game day setting.

📄️ AssetUpdateWeatherPreviewLock

Locks or unlocks the weather preview setting.

📄️ AssetUpdateModelPreview

Updates the model preview settings.
